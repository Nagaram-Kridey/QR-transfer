# LumenLink phase-plan index

The accepted schedule, scope gates and milestones are maintained in
[PROJECT_PLAN.md](PROJECT_PLAN.md). Ordered tasks, dependencies, verification commands and checked
execution status are maintained in [IMPLEMENTATION_PLAN.md](IMPLEMENTATION_PLAN.md).
[UPDATE.md](UPDATE.md) records each meaningful update and its next actions.

Sequence: foundation → repeat baseline and real-camera feasibility → early portfolio demo →
production browser receiver/PWA → complete security/compression → bounded LT comparison → release.

Current position: foundation and Stage 1 software implemented; real Android/iPhone trials pending.
The physical gate is not passed by synthetic camera tests. Security/PWA/fountain/release work
must follow the gate. Earlier drafts are preserved under `docs/planning/original/`.
